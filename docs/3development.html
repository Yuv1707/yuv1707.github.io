Knowledge and Skills Development

This section outlines my strategy for professional growth. It includes a mix of long-term planning and short-term CPD activities undertaken during the module to address skill gaps identified earlier.

Development Plan Summary

  • Long-term: Pursue certifications in software engineering (e.g., AWS, Google Associate Developer), secure an internship or placement year, and continue contributing to open-source projects.
  • Short-term: Participate in NTU employability workshops, complete LinkedIn Learning courses on Git/GitHub, JavaScript and APIs, and improve algorithm problem-solving using coding challenge platforms.

Completed CPD Activities

  • Advanced Python – LinkedIn Learning (5 hours): Focused on real-world data problems
  • Creating a Winning CV – NTU Workshop (2 hours): Improved application techniques
  • Working in Data Workshop (2 hours): Realised team dynamics in data projects
  • Design Thinking Workshop (2 hours): Practiced innovation, teamwork and design approaches
  • Testing Workshop (2 hours): Developed quality assurance mindset and group feedback handling
  • JavaScript & API Development – LinkedIn Learning (5 hours): Learned to build and consume REST APIs
  • Git & GitHub – LinkedIn Learning (4 hours): Improved version control workflow and collaboration
  • Algorithm Problem Solving Practice (LeetCode & HackerRank) (5 hours): Weekly practice of programming tasks and coding challenges
  • Attended Virtual BCS Webinar on Software Development Practices (3 hours): Broadened understanding of Agile methodologies and secure coding practices

These activities total over 30 hours of formal and self-directed CPD, with additional reflection, reading and documentation practices easily extending the total to 30+ hours. This plan reflects a consistent effort to address skills gaps and align with my career goals in software engineering.
